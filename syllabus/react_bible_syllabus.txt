SECTION 1: THE COMPLETE 19 REACT HOOKS & 19.2 ADDITIONS REFERENCE
--------------------------------------------------------------------------------
1.1 State & Lifecycle Hooks
    1. useState            - Fiber node state link list, lazy initializers, functional updates, automatic batching.
    2. useReducer          - Complex state machines, action dispatch pipelines, pure reducer contracts.
    3. useEffect           - Post-paint side effect synchronization, cleanup function ordering, strict mode dev re-runs.
    4. useLayoutEffect     - Pre-paint synchronous layout mutations, DOM measurement timing.
    5. useInsertionEffect  - Style tag injection for CSS-in-JS libraries before layout computation.
    6. useEffectEvent      - (React 19.2) Extracting non-reactive event logic from effects without re-triggering effect execution.

1.2 DOM & Mutable Reference Hooks
    7. useRef              - Persistent mutable container (.current), DOM node binding, ref cleanup callbacks in React 19.
    8. useImperativeHandle - Customizing imperative ref handles exposed to parent components.

1.3 Performance & Memoization Hooks
    9. useMemo             - Caching expensive CPU computations based on dependency array equality.
    10. useCallback        - Retaining function instance identity across re-renders.

1.4 Context & External Store Hooks
    11. useContext         - Consuming context values, Provider subtree re-render triggers.
    12. useSyncExternalStore - Atomic reads from external stores (Redux, Zustand, Web APIs) without tearing.

1.5 Concurrent & Non-Blocking Hooks
    13. useTransition      - Low-priority state updates (isPending, startTransition).
    14. useDeferredValue   - Deferring re-renders of heavy UI subtrees during high-frequency user input.

1.6 Form & Action Hooks (React 19+)
    15. useActionState     - Async server/client action status, pending states, error handling.
    16. useFormStatus      - Child component awareness of parent <form> submission status.
    17. useOptimistic      - Instant UI mutations with automatic server rollback on failure.

1.7 Universal Resource & Context Hook (React 19+)
    18. use                - Unwrapping Promises and reading Context conditionally inside render branches/loops.

1.8 Accessibility, ID & Debugging Hooks
    19. useId              - Hydration-safe SSR/Client unique identifier generation for ARIA attributes.
    20. useDebugValue      - Custom label display inside React Developer Tools.

SECTION 7: INDUSTRY-READY CUSTOM HOOKS & PATTERNS
--------------------------------------------------------------------------------
7.1 Timing & Input Hooks
    - useDebounce           - Deferring a fast-changing value/callback until input settles.
    - useThrottle           - Capping how often a value/callback updates within a window.
    - useInterval / useTimeout - Declarative, effect-safe wrappers over setInterval/setTimeout.

7.2 Browser & DOM Interaction Hooks
    - useOnClickOutside     - Detecting clicks outside a ref'd element (dropdowns, modals).
    - useEventListener      - Attaching/cleaning up a DOM/window event listener declaratively.
    - useWindowSize         - Reactive viewport width/height with resize-listener cleanup.
    - useMediaQuery         - Reactive boolean binding to a CSS media query via matchMedia.
    - useHover              - Tracking pointer-enter/leave state on a ref'd element.

7.3 State & Storage Hooks
    - useLocalStorage / useSessionStorage - State synced to Web Storage, cross-tab-safe variants.
    - usePrevious           - Capturing a value's previous render via a ref + effect.
    - useToggle             - Boolean state with a stable toggle callback.
    - useUpdateEffect       - useEffect that skips the initial mount run.

7.4 Data Fetching & Async Hooks
    - useFetch / useAsync   - Encapsulated loading/data/error state around an async call.
    - Abortable-effect pattern - Cancelling in-flight requests on dependency change/unmount via AbortController.
    - Optimistic update with rollback - Applying a UI change immediately, reverting on server failure.

7.5 Performance Patterns
    - Virtualized list rendering - Rendering only visible rows/items for large collections (windowing).
    - Infinite scroll       - IntersectionObserver-driven incremental data loading.
    - React.lazy + Suspense code-splitting - Deferring component bundles until first render.
    - Memoized selector pattern - Deriving state without recomputation/re-renders on unrelated changes.

7.6 Composition Patterns
    - Compound components   - Parent/child components sharing implicit state via context.
    - Render props           - Passing a function-as-child/prop to control what gets rendered.
    - Higher-Order Components (HOC) - Wrapping a component to inject props/behavior.
    - Controlled vs uncontrolled - Owning input state via props+onChange vs. letting the DOM own it.
    - Context + useReducer store - A lightweight app-store pattern without external state libraries.

7.7 Reliability Patterns
    - Error boundaries       - Class-based getDerivedStateFromError/componentDidCatch fallback UI.
    - Retry-on-error UI      - Surfacing a retry affordance instead of a dead error screen.
    - Portal-based modals/tooltips - Rendering outside the DOM parent while preserving React tree context.
