SECTION 1: THE COMPLETE 19 REACT HOOKS REFERENCE
--------------------------------------------------------------------------------
1.1 State & Lifecycle Hooks
    1. useState            - Fiber node state link list, lazy initializers, functional updates, automatic batching.
                             [Edge Cases: Stale closures in async callbacks, direct object mutations bypassing reconciliation].
    2. useReducer          - Complex state machines, action dispatch pipelines, pure reducer contracts.
                             [Edge Cases: Impure Reducer side-effects, state mutation vs object replacement].
    3. useEffect           - Post-paint side effect synchronization, cleanup function ordering, strict mode dev re-runs.
    4. useLayoutEffect     - Pre-paint synchronous layout mutations, DOM measurement timing.
                             [Edge Cases: SSR layout warning, blocking browser rendering thread].
    5. useInsertionEffect  - Style tag injection for CSS-in-JS libraries before layout computation.
                             [Edge Cases: Restricted state update triggers inside effect].

1.2 DOM & Mutable Reference Hooks
    6. useRef              - Persistent mutable container (.current), DOM node binding, ref cleanup callbacks in React 19.
                             [Edge Cases: Reading/writing .current during render cycle causes non-deterministic UI].
    7. useImperativeHandle - Customizing imperative ref handles exposed to parent components.
                             [Edge Cases: Overusing imperative escape hatches breaking declarative React paradigm].

1.3 Performance & Memoization Hooks
    8. useMemo             - Caching expensive CPU computations based on dependency array equality.
                             [Edge Cases: Memory overhead of storing memo caches vs cheap recalculation cost].
    9. useCallback         - Retaining function instance identity across re-renders.
                             [Edge Cases: Missing variables in dependency array creating stale event handlers].

1.4 Context & External Store Hooks
    10. useContext         - Consuming context values, Provider subtree re-render triggers.
                             [Edge Cases: Un-memoized value objects causing whole-app re-renders on any parent update].
    11. useSyncExternalStore - Atomic reads from external stores (Redux, Zustand, Web APIs) without tearing.
                             [Edge Cases: Returning new object literals in getSnapshot causing infinite re-render loops].

1.5 Concurrent & Non-Blocking Hooks
    12. useTransition      - Low-priority state updates (isPending, startTransition).
                             [Edge Cases: Wrapping controlled input values directly inside transition state].
    13. useDeferredValue   - Deferring re-renders of heavy UI subtrees during high-frequency user input.
                             [Edge Cases: Misunderstanding deferred value as a debouncer; it triggers background re-renders].

1.6 Form & Action Hooks (React 19+)
    14. useActionState     - Async server/client action status, pending states, error handling.
                             [Edge Cases: Handling form re-submissions during ongoing async promises].
    15. useFormStatus      - Child component awareness of parent <form> submission status.
                             [Edge Cases: Must be called INSIDE a component nested under the <form>, not in the form component itself].
    16. useOptimistic      - Instant UI mutations with automatic server rollback on failure.
                             [Edge Cases: Rapid multi-click race conditions; requires backend idempotency keys].

1.7 Universal Resource & Context Hook (React 19+)
    17. use                - Unwrapping Promises and reading Context conditionally inside render branches/loops.
                             [Edge Cases: Passing un-memoized inline Promises creates infinite Suspense loading loops].

1.8 Accessibility, ID & Debugging Hooks
    18. useId              - Hydration-safe SSR/Client unique identifier generation for ARIA attributes.
                             [Edge Cases: Do NOT use useId for generating database key props in arrays].
    19. useDebugValue      - Custom label display inside React Developer Tools.

SECTION 2: REACT CLIENT APIS (react-dom/client & react-dom)
--------------------------------------------------------------------------------
2.1 Client Rendering APIs (react-dom/client)
    - createRoot()         - Concurrent root initialization, .render(), .unmount().
                             [Edge Cases: Calling createRoot multiple times on same DOM node].
    - hydrateRoot()        - Hydrating server HTML into interactive client tree.
                             [Edge Cases: Hydration mismatches caused by window/Date/Math.random discrepancies].

2.2 DOM Portal & Mutation APIs (react-dom)
    - createPortal()       - Mounting subtrees outside DOM hierarchy while maintaining React event bubbling.
                             [Edge Cases: Event bubbling trickling up React tree despite separate DOM tree node].
    - flushSync()          - Forcing React to bypass batching and flush pending DOM updates synchronously.
                             [Edge Cases: Severe performance degradation if overused; breaks Concurrent mode optimizations].
