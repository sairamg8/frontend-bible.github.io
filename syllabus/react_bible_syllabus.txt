SECTION 1: THE COMPLETE 19 REACT HOOKS & 19.2 ADDITIONS REFERENCE
--------------------------------------------------------------------------------
1.1 State & Lifecycle Hooks
    1. useState            - Fiber node state link list, lazy initializers, functional updates, automatic batching.
    2. useReducer          - Complex state machines, action dispatch pipelines, pure reducer contracts.
    3. useEffect           - Post-paint side effect synchronization, cleanup function ordering, strict mode dev re-runs.
    4. useLayoutEffect     - Pre-paint synchronous layout mutations, DOM measurement timing.
    5. useInsertionEffect  - Style tag injection for CSS-in-JS libraries before layout computation.
    6. useEffectEvent      - (React 19.2) Extracting non-reactive event logic from effects without re-triggering effect execution.

1.2 DOM & Mutable Reference Hooks
    7. useRef              - Persistent mutable container (.current), DOM node binding, ref cleanup callbacks in React 19.
    8. useImperativeHandle - Customizing imperative ref handles exposed to parent components.

1.3 Performance & Memoization Hooks
    9. useMemo             - Caching expensive CPU computations based on dependency array equality.
    10. useCallback        - Retaining function instance identity across re-renders.

1.4 Context & External Store Hooks
    11. useContext         - Consuming context values, Provider subtree re-render triggers.
    12. useSyncExternalStore - Atomic reads from external stores (Redux, Zustand, Web APIs) without tearing.

1.5 Concurrent & Non-Blocking Hooks
    13. useTransition      - Low-priority state updates (isPending, startTransition).
    14. useDeferredValue   - Deferring re-renders of heavy UI subtrees during high-frequency user input.

1.6 Form & Action Hooks (React 19+)
    15. useActionState     - Async server/client action status, pending states, error handling.
    16. useFormStatus      - Child component awareness of parent <form> submission status.
    17. useOptimistic      - Instant UI mutations with automatic server rollback on failure.

1.7 Universal Resource & Context Hook (React 19+)
    18. use                - Unwrapping Promises and reading Context conditionally inside render branches/loops.

1.8 Accessibility, ID & Debugging Hooks
    19. useId              - Hydration-safe SSR/Client unique identifier generation for ARIA attributes.
    20. useDebugValue      - Custom label display inside React Developer Tools.
