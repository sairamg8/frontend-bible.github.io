================================================================================
                           THE ULTIMATE FRAMER MOTION BIBLE
              Complete Master Syllabus for Motion (Framer Motion) & APIs
================================================================================

--------------------------------------------------------------------------------
SECTION 1: CORE CONCEPTS
--------------------------------------------------------------------------------
1.1 Declarative Animation Philosophy
    - motion components                     - motion.div, motion.svg, etc. - drop-in animatable HTML/SVG elements.
    - Declarative state-driven animation        - Describing "what state looks like," letting Motion interpolate the transition.
    - motion(Component)                            - Making a custom component animatable via forwardRef.


--------------------------------------------------------------------------------
SECTION 2: BASIC ANIMATION PROPS
--------------------------------------------------------------------------------
2.1 The Core Prop Triad
    - initial                              - Starting style/state on mount.
    - animate                                 - Target style/state to animate toward.
    - exit                                       - Target style/state on unmount (requires AnimatePresence).
    - transition                                    - Per-property or global timing/easing configuration for the animate prop.


--------------------------------------------------------------------------------
SECTION 3: TRANSITION TYPES
--------------------------------------------------------------------------------
3.1 Timing Models
    - tween                                - Duration-based easing curve animation (ease, duration, delay).
    - spring                                  - Physics-based motion (stiffness, damping, mass) - the default for most value types.
    - inertia                                    - Momentum-based deceleration, used for drag release/fling gestures.


--------------------------------------------------------------------------------
SECTION 4: VARIANTS
--------------------------------------------------------------------------------
4.1 Reusable Named States
    - Defining variants                     - { hidden: {...}, visible: {...} } objects referenced by name via animate="visible".
    - Orchestration                            - staggerChildren, delayChildren on a parent variant.
    - Propagation                                - Child motion components automatically inherit parent variant changes without individually re-specifying animate.


--------------------------------------------------------------------------------
SECTION 5: GESTURES
--------------------------------------------------------------------------------
5.1 Interaction-Driven Animation
    - whileHover / whileTap / whileFocus      - Temporary style states bound to pointer/focus interaction.
    - whileDrag                                  - Style state applied during an active drag gesture.
    - drag                                          - Enabling free/axis-constrained dragging (drag="x" | "y" | true).
    - dragConstraints / dragElastic / dragMomentum   - Bounding, resistance, and release-momentum tuning.


--------------------------------------------------------------------------------
SECTION 6: ANIMATEPRESENCE
--------------------------------------------------------------------------------
6.1 Exit Animations
    - Why it's needed                        - React unmounts synchronously; AnimatePresence delays actual removal until exit completes.
    - mode prop                                 - 'sync' (default), 'wait' (sequential exit-then-enter), 'popLayout' (removed element pops out of flow immediately).
    - Keying children correctly for AnimatePresence to detect add/remove.


--------------------------------------------------------------------------------
SECTION 7: LAYOUT ANIMATIONS
--------------------------------------------------------------------------------
7.1 Automatic Layout Transitions
    - layout prop                           - Automatically animates position/size changes caused by layout/DOM reflow (FLIP technique under the hood).
    - layout="position" / layout="size"        - Restricting automatic animation to only position or only size changes.
    - layoutId                                    - Shared element transitions between different components/routes (magic-move animation).


--------------------------------------------------------------------------------
SECTION 8: SCROLL-LINKED ANIMATIONS
--------------------------------------------------------------------------------
8.1 Scroll-Reactive Motion
    - useScroll                             - scrollX/scrollY and progress motion values tied to a scroll container or the page.
    - whileInView                              - Triggering an animation when an element enters the viewport, with viewport: { once, amount } options.
    - Combining useScroll + useTransform for parallax/scroll-progress-driven effects.


--------------------------------------------------------------------------------
SECTION 9: MOTION VALUES
--------------------------------------------------------------------------------
9.1 Imperative Value Tracking
    - useMotionValue()                      - A value that can update outside React's render cycle for high-frequency animation (avoids re-renders).
    - useTransform()                           - Mapping one motion value's range into another (e.g. scroll progress -> opacity).
    - useSpring()                                - Wrapping a motion value with spring physics smoothing.


--------------------------------------------------------------------------------
SECTION 10: ANIMATION CONTROLS
--------------------------------------------------------------------------------
10.1 Imperative Sequencing
    - useAnimation() / useAnimate()          - Programmatically starting/stopping/sequencing animations outside of prop-driven state.
    - Chaining animations                       - await animate(...) sequencing for multi-step choreography.
    - Manually triggering variant changes on specific elements via controls.start('variantName').


--------------------------------------------------------------------------------
SECTION 11: KEYFRAMES
--------------------------------------------------------------------------------
11.1 Multi-Step Value Animation
    - Array syntax                          - animate={{ x: [0, 100, 0] }} for multi-keyframe motion in one call.
    - times array                              - Fine-grained control over when each keyframe occurs within the total duration.


--------------------------------------------------------------------------------
SECTION 12: SVG ANIMATIONS
--------------------------------------------------------------------------------
12.1 Vector Graphic Motion
    - pathLength / pathOffset / pathSpacing   - Animating stroke drawing effects on SVG paths.
    - Morphing between path shapes (with caveats on matching point counts).
    - Animating SVG-specific attributes (viewBox, fill, stroke) via standard motion props.


--------------------------------------------------------------------------------
SECTION 13: ORCHESTRATION & STAGGERING
--------------------------------------------------------------------------------
13.1 Choreographed Groups
    - Parent-child timing control              - staggerChildren, staggerDirection, delayChildren on container variants.
    - Custom per-child stagger via the `custom` prop passed into a variant function.


--------------------------------------------------------------------------------
SECTION 14: PERFORMANCE CONSIDERATIONS
--------------------------------------------------------------------------------
14.1 Animating Efficiently
    - GPU-accelerated properties               - Preferring transform/opacity over top/left/width/height for 60fps animation.
    - Avoiding layout-triggering animated properties where a transform equivalent exists.
    - will-change implications                    - When Motion applies it automatically and the memory/compositing tradeoffs.


--------------------------------------------------------------------------------
SECTION 15: ADVANCED PATTERNS
--------------------------------------------------------------------------------
15.1 Production-Grade Motion Design
    - Shared layout transitions across routes     - layoutId-based element continuity in page transitions.
    - Exit-before-enter page transitions             - AnimatePresence mode="wait" wrapping route-level components.
    - Next.js App Router integration                   - Handling client-only AnimatePresence boundaries within Server Component trees.
    - Reduced-motion accessibility                       - Respecting prefers-reduced-motion via useReducedMotion().
